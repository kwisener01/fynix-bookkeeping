# App Icons Needed

Please generate the following app icons:

## Required Icons:
1. **icon-192.png** - 192x192px PNG
2. **icon-512.png** - 512x512px PNG

## Design Guidelines:
- Background: White (#ffffff)
- Primary Color: Blue (#2563eb)
- Logo: "F" or receipt icon
- Format: PNG with transparency
- Purpose: PWA home screen icons

## Quick Generation Options:

### Option 1: Online Tool
Visit: https://www.pwabuilder.com/imageGenerator
- Upload a square logo (512x512)
- Generate all icon sizes
- Download and place in `/frontend/public/`

### Option 2: Figma/Canva
- Create 512x512 canvas
- Design simple "F" logo with blue background
- Export as PNG
- Resize to 192x192 for smaller icon

### Option 3: Simple Placeholder
For testing, you can use any square PNG images renamed to:
- `icon-192.png`
- `icon-512.png`

The icons will appear on the mobile home screen when users install the PWA.
