## 🚀 Quick Start (2-Week Launch)

### Week 1: Infrastructure

**Day 1-2: Supabase**
1. Create account at [supabase.com](https://supabase.com)
2. Create new project
3. Run `database/schema.sql` in SQL Editor
4. Set up storage for receipts
5. Save your API keys

**Day 3-4: Railway (Backend)**
1. Create account at [railway.app](https://railway.app)
2. Push code to GitHub
3. Deploy from GitHub repo
4. Add environment variables
5. Test: `curl https://your-api.railway.app/health`

**Day 5: Domain**
1. Buy domain (e.g., fynixbooks.com)
2. Point to Railway & Vercel

### Week 2: Frontend & Testing

**Day 6-8: Vercel (Frontend)**
1. Follow `frontend/SETUP.md`
2. Create Next.js app
3. Copy frontend files
4. Deploy to Vercel
5. Add environment variables

**Day 9-11: Testing**
- Test signup/login
- Upload receipts
- Verify categorization
- Check job matching

**Day 12-14: Beta**
- Invite 3-5 contractors
- Get feedback
- Fix bugs
- Prepare launch!
